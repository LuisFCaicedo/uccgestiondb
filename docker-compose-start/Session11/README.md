# Generador de Datos para Banco con PostgreSQL y Python

Este proyecto simula la creación de cuentas bancarias y transacciones aleatorias, insertándolas en una base de datos PostgreSQL.

## 🧰 Requisitos

- Python 3.7 o superior
- PostgreSQL funcionando localmente o en red
- Un usuario PostgreSQL con permisos de inserción
